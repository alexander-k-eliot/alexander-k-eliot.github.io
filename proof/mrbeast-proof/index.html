Whoever built this side of the business actually thought about what happens when an AI agent, not a browser, is the one shopping.

Methodology and honest scope

Checks performed 2026-07-25 against each site's live public homepage: robots.txt (present/absent, verified as a real plain-text file and not a soft-404 HTML page served under a 200 status, by checking both status code and content-type), llms.txt (same verification), XML sitemap reachability, homepage <title>, meta description, canonical tag, JSON-LD structured-data blocks, and H1 heading count. mrbeast.com was checked twice independently (direct server fetch and a real rendered browser session) before being reported as non-functional, to rule out a transient network issue rather than a real site problem. Scores are directional (~) rounded estimates using the same weighting as this studio's published 158-site industry benchmark, not a decimal-precision claim. Beast Games (streaming deal, no standalone public marketing site found) and MrBeast Studios (no distinct public site found separate from the main YouTube channel) were not included as they had no independent website to check.
