Hey ChatGPT, Am I Real?

This studio sells a tool that checks whether AI assistants can find and correctly describe other people's businesses. So it ran the exact same test on itself, right now, live, against the real assistants people actually use. Every result below is unedited, including a factual mix-up two different AI assistants both made about this business's own name.

The test: ask a real AI assistant, cold, no hints. "what is Click Coded, the business at clickcoded.com? Who runs it and what does it do?", and report exactly what came back, or exactly what stopped the question from being asked at all.

What actually happened

Answered, and got it wrong

ChatGPT. Misidentified this business as someone else's real company

Asked anonymously, no account: ChatGPT correctly said it couldn't verify the GitHub Pages site as an official business site. A fair, honest hedge. Then it filled the gap with a real, unrelated company: AE Studio at ae.studio, and named its actual real founder and CEO, Judd Rosenblatt, plus two other real named executives, as if they ran this one. A specific, confident, entirely wrong attribution to real people who have nothing to do with this business.

Answered. Same mix-up

Perplexity. The identical misattribution, independently

Asked the same question, anonymously, no account: Perplexity gave the same answer as ChatGPT. "Click Coded appears to be AE Studio at ae.studio," describing that unrelated company's real focus (agency-model software and alignment research) as if it were this one. Two different assistants, same specific wrong answer, which makes it look less like a fluke and more like the name collision itself is what's steering both of them.

Walled off

Microsoft Copilot. No anonymous path at all

Copilot's own landing page requires signing in with Microsoft, Apple, or Google before any question can be asked, with no visible guest option. Same result as ChatGPT: not testable anonymously today.

Confusing, not absent

Plain search (Bing, DuckDuckGo). Found the studio, but next to a different one

Regular search results did surface this studio's own real pages. They also surfaced an unrelated, pre-existing brand using a nearly identical name, "æ.studio" and the æternity crypto project, mixed into the same results page. A search engine's crawler can find this business. It can also hand a reader a completely different company by mistake, because the name collides with one that already existed first.

Answered directly

Claude. The one assistant that could actually answer, because it's the one writing this page

No login wall applies here, for an obvious reason: this page is being written by a live Claude session. So the honest test is simple. Does this specific AI, unprompted, already know what Click Coded is? It doesn't. Nothing about this business appears in this model's training. That's not a surprising result for a business this new, but it's the same honest negative result this studio's own paid audits report for other companies every day. Reported here about itself, first.

A separate run, a different wrong answer

Perplexity, asked again later. Didn't repeat the mix-up, invented a new one

A second, independent anonymous session asked Perplexity a slightly different version of the same question. This time it didn't reach for the AE Studio mix-up at all. It confidently described a product that doesn't exist: an AI-visibility platform it called "Alex," claiming it "runs a brand across ChatGPT, Gemini, Perplexity, and Google AI Overview simultaneously," returns a "visibility score" percentage, and produces a "competitor leaderboard." It cited 15 sources for a product that was never built. None of it is real: this studio's actual free checker is a single-URL, 9-check score against a published 158-company study. No leaderboard, no percentage metric, no "Alex." Same assistant, same business, two different sessions, two different fabrications, which says less about one bad answer and more about how little grounding is there for either one.

The honest total

Zero for five. Copilot couldn't be tested anonymously at all. ChatGPT and Perplexity both answered confidently and both got it wrong the same way. Handing a stranger the real name of a different company's real CEO instead of admitting they didn't know. Plain search found the right pages, but seated them next to that same unrelated company in the results. And this session's own Claude instance, asked the same question cold, simply had never heard of this business at all. Every path a stranger might actually take ends somewhere other than a clean, correct answer. That's the real, current starting point. Not a number this studio would pick to advertise, which is exactly why it's the one being published.
