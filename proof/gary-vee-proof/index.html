Methodology and honest scope

Checks performed 2026-07-25 against each site's live public homepage: robots.txt (present/absent, verified as a real plain-text file and not a soft-404 HTML page served under a 200 status), llms.txt (same verification), XML sitemap reachability, homepage <title>, meta description, canonical tag, JSON-LD structured-data blocks, and H1 heading count. The same categories this studio's free public checker runs. Sites that returned bot-detection challenge pages to a direct server-side fetch (none in this portfolio, unlike a prior audit) would have been re-verified via a real rendered browser rather than reported as-is. All five sites here were fetchable directly.
