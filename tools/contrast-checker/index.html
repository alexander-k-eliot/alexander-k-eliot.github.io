The real WCAG 2.2 thresholds

  • AA normal text: 4.5:1 minimum.
  • AA large text (18pt+, or 14pt+ bold) and UI components: 3:1 minimum.
  • AAA normal text: 7:1 minimum.
  • AAA large text: 4.5:1 minimum.
