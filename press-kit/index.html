Methodology

How every score gets made

The same nine-point, weighted rubric runs on every site in every report. No bespoke scoring per industry, no manual adjustment.

01

One respectful fetch

A single server-side request per homepage, a clearly identifying User-Agent, public data only. No login walls crossed, no rate-limit abuse.

02

Nine weighted checks

Title & meta description, structured data (JSON-LD), heading structure, answer-shaped content, readability without JavaScript, a findable contact path, llms.txt, robots.txt, and an XML sitemap.

03

Honest-scope scoring

A site that blocks the fetcher (403, timeout) is reported as blocked, never scored as a zero. Checks that can't run are excluded from that site's denominator, not counted against it.
